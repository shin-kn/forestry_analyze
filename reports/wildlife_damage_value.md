---

## 0. 検証する仮説

ideas.md の記述:

> 積極的に、人里から近かったり農地から近い森・林を**取得**し、熊・鹿などの害獣を**駆除・近づけない**ことから価値を生む

検証すべき論点は3つ。**(1) 被害の規模＝市場はあるか、(2) 誰が金を払うのか、(3) 森林の取得は必要か。**

---

## 1. 被害の規模

### 森林被害

| 項目 | 数値 |
|---|---|
| 野生鳥獣による森林被害面積（2024年度） | **4,256ha**（前年度から904ha減） |
| うちシカによる被害 | 全体の**約6割** |
| トレンド | **近年減少傾向** |

### 農作物被害

| 項目 | 数値 |
|---|---|
| 農作物被害額（2024年度） | **187億5,800万円** — 過去10年で最大 |
| うちシカ | 79億円 |
| うちイノシシ | 45億円 |
| 上位2種で | 被害額の**約2/3** |

**森林被害は減少傾向、農作物被害は過去10年で最大。** 金額規模でも農業側が圧倒的に大きい。**価値の源泉は林業ではなく農業側にある。**

### 個体数と捕獲

| 項目 | 数値 |
|---|---|
| シカ個体数（2023年度末、北海道除く） | **230万頭** |
| シカ分布域の拡大（1978→2018年度） | **約2.7倍** |
| 2011年度の個体数 | シカ310万頭、イノシシ121万頭 |
| 政府目標 | 2028年度までに2011年度比で**半減** |
| 2024年度捕獲頭数 | シカ**73.9万頭**（+2.2%）、イノシシ**64.3万頭**（+23.2%） |

クマについては、2024年4月に**クマ類が指定管理鳥獣に指定**され、「クマ被害対策施策パッケージ」が公表されている。人身被害が生活圏・森林内で多発している状況を受けた措置。

---

## 2. 誰が金を払うのか

「価値を生む」の実体を確認すると、**原資の中心は公費**である。

### (a) 既存の制度

| 制度 | 内容 |
|---|---|
| 鳥獣被害防止特措法（2007年制定） | 市町村が被害防止計画を作成 |
| 鳥獣被害防止総合対策交付金 | 被害防止計画に基づく捕獲・被害防除・生息環境管理を支援。**交付率1/2または定額** |
| 森林整備事業（林野庁） | 造林等の施業と一体となった**防護柵等の被害防止施設**の整備、囲いわな等による誘引捕獲を支援 |
| シカ等による森林被害緊急対策事業 | 生息場所の確認、**捕獲個体処理施設の配備**等 |

**既に公的支援の枠組みが整っている。** 裏を返せば、収益は交付金に依存する構造になる。

### (b) ジビエ

| 項目 | 数値 |
|---|---|
| ジビエ利用量（2023年度） | **2,729トン**（前年比 +30.9%） |
| 処理加工施設数（2022年度） | 750か所 |
| 2016年度比 | 1.6倍 |

成長率は高いが**絶対量が小さい**。捕獲頭数シカ73.9万頭に対して2,729トンは、1頭あたり可食部を仮に20kgとしても約13万頭分にすぎず、**捕獲個体の大半は利用されていない**。

### (c) 造林費の削減 — 林業側の直接的な価値

白書の造林初期費用307万円/haの試算根拠には、こう書かれている。

> スギ3,000本/ha植栽、下刈り5回、**獣害防護柵400m**として試算

つまり**防護柵は造林費に織り込み済みのコスト**。獣害圧が下がれば、この分が直接削減できる。[耕作放棄地への植樹レポート](farmland_afforestation.md) で見たとおり造林は土地代ゼロでも126万円/ha赤字なので、ここの削減は効く。

---

## 3. 「森林を取得する」は必要か

**不要であり、かつ不利。**

- **造林の採算は土地代ゼロでも126万円/ha赤字**（造林費307万円 vs 山元立木価格181万円）。土地取得はこの赤字に上乗せされる
- **獣害対策の実施に所有権は要らない**。捕獲は狩猟免許と市町村の許可、防護柵設置は森林整備事業の支援対象、緩衝帯整備は活性化法の事業メニュー
- 白書は**鳥獣緩衝帯の整備**を「農山漁村の活性化のための定住等及び地域間交流の促進に関する法律」に基づく農用地保全事業のメニューとして挙げている

**所有ではなく受託の形にすれば、資産リスクを負わずに同じ活動ができる。**

---

## 4. 担い手の状況

| 項目 | 数値 |
|---|---|
| 狩猟免許交付数 | 約21万件（重複所持を含む） |
| 実際の狩猟者数 | 約15万人 |
| 60歳以上の比率（2020年） | **58.3%** |
| 20〜40代の狩猟免許取得者 | 2010年 27,800人 → 2020年 **60,000人**（倍増） |
| 免許種別の傾向 | **わな猟免許が銃猟免許を上回った** |

高齢化は進んでいるが、**若年層は倍増しており、わな猟が主流化**している。わな猟は銃猟より参入障壁が低く、事業化の担い手確保という点では追い風。

白書も、林業側から捕獲人材を育てる動きを記録している（宮崎県国富町の事例で、整備した森林を活用し、新たに狩猟に取り組む者を対象にわなの設置方法等の技術指導）。

## 5. 論点の再整理

| 論点 | 評価 |
|---|---|
| **森林の取得**（既出） | **不要**。捕獲・防護柵・緩衝帯整備はいずれも所有権と無関係。取得は赤字を上乗せするだけ |
| 収益源 | **交付金・補助金が中心**。ジビエは高成長だが絶対量が小さい |
| 市場規模 | 農作物被害188億円 ≫ 森林被害。**農業側が主戦場** |
| 森林被害のトレンド | **減少傾向**（4,256ha、前年度比 -904ha）。林業側の課題としては縮小方向 |
| 担い手 | 60歳以上58.3%だが20〜40代は倍増。わな猟が主流化し参入余地あり |
| 造林費との関係 | 防護柵400m/haが造林費に計上済み。獣害圧の低下は造林費削減に直結 |
| クマ | 2024年に指定管理鳥獣化。政策的な優先度が上がっている |

---

## 6. 暫定結論

**「森林を取得して」の部分は落としたほうがよい。** 所有権は獣害対策に必要なく、造林の赤字構造を抱え込むだけになる。**獣害対策サービスの受託**（捕獲、防護柵設置、緩衝帯整備、捕獲個体処理）のほうが、資産リスクなしに同じ交付金を収益化できる。

ただし2点、直視すべき前提がある。

1. **原資の中心が公費**である。交付金の設計変更に事業性が左右される
2. **森林被害は減少傾向**（4,256ha）で、金額規模は農作物被害（188億円）が圧倒的。**林業アイデアというより農業側のサービス事業**になる

### 他のアイデアとの接続

[耕作放棄地への植樹](farmland_afforestation.md) と組み合わせる設計はありうる。耕作放棄地は獣害の温床であり、白書は活性化法の農用地保全事業に**林地化と鳥獣緩衝帯整備の両方**をメニューとして挙げている。**同じ土地で、同じ制度の枠内で、両方を受託する**構成は制度上も自然。

またそのレポートでは獣害を「不利な点」として挙げたが、獣害対策自体を事業に取り込めばリスクではなく収益機会に転じる。
