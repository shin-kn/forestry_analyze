## 0. 検証する仮説

### 現状認識

**(1) 現地聞き取り調査より**（一次情報）
- 小口の業者は、工場などに対してあまり価格交渉力がない
- 苗などで、需要と供給がマッチせず**成長しすぎてしまっている苗**がある

**(2) データ分析より**（本リポジトリの既存レポート）
- コストの主要因は伐採費で、そのメインは1人当たり生産性に依存する
- 販管費23%は、地形的要因に支配される生産性と違って改善が見込める可能性がある

### アイデア

林業関係資材（苗木・丸太・加工後の資材）の "Amazon" をつくる。
- 競合他社とも**物流倉庫を共同化**
- オンライン上で**すべての供給が見えて、かつ注文可能**

## 1. 前提の検証 — 販管費23%に改善余地はあるか

**結論: 改善余地はある。しかも金額的なインパクトは大きい。**

### 1.1 日墺比較 — 日本が特に非効率なわけではない

ideas.md は「要オーストリアとの比較、だが外注費にまとめられているので難しいか」としているが、**Forstbericht は費目別（Kostenarten）と部門別（Kostenstellen）の両建てで公表しており、部門別で管理費が独立しているため比較できる**。

| | 日本（会社経営体, H30） | オーストリア（Forstbericht 2022） |
|---|---|---|
| 管理・一般経費 | 販売費・一般管理費 **2,705円/m³** | Verwaltung / allgem. Betrieb **16.60 €/m³ ≒ 2,739円/m³** |
| 比 | 1.00 | **1.01** |

ほぼ同水準。

**ただしこれは「改善余地がない」ことを意味しない。** オーストリアは理論的な最適値ではなく、単なる比較対象の1つにすぎない。**両国とも同程度に非効率である可能性**を示しているだけで、絶対的な下限を示すものではない。

言えるのは「**日本の販管費が特別に高いわけではない**」ということまで。

なお構造上の注意として、オーストリアは外注費が58.3%を占めるため、日本なら販管費に計上される機能の一部が**請負業者の価格に埋め込まれている**可能性がある。この点でも単純比較には限界がある。

### 1.2 削減余地の証拠 — 白書自身が示している

鳥取県デジタル林業コンソーシアムの事例（白書 事例2-5）:

> 見積・納品情報や県産材証明などを紙で運用しており、資料が膨大となり事務処理が煩雑になっていた（中略）**県産材証明書については、約8割のコスト削減が可能と試算**

**販管費に含まれる事務コストが、デジタル化で実際に削減できるという直接的な証拠。** 8割という数字は証明書発行事務に限定されたものだが、同種の紙運用が販管費の他の部分にも残っていると考えるのが自然。

### 1.3 削減のインパクト

販管費 **2,705円/m³** は、丸太価格15,400円/m³の **17.6%**、山元立木価格4,026円/m³の **67%** に相当する。

削減が山元立木価格に与える影響:

| 販管費の削減率 | 削減額 | 山元立木価格 | 上昇率 |
|---|---|---|---|
| 20% | 541円/m³ | 4,567円/m³ | **+13%** |
| 30% | 812円/m³ | 4,838円/m³ | **+20%** |
| 50% | 1,352円/m³ | 5,378円/m³ | **+34%** |
| 80% | 2,164円/m³ | 6,190円/m³ | **+54%** |

**販管費は山元立木価格に対して大きい。** 伐出費（9,000〜10,400円/m³）ほどの規模ではないが、**山元立木価格を動かす効果としては十分に大きい。**

### 1.4 伐出費との比較

| | 日本 | オーストリア | 改善手段 |
|---|---|---|---|
| 伐出費 | 9,000〜10,400円/m³ | 4,546円/m³ | 路網整備・機械化（**プラットフォームでは動かせない**） |
| 販管費 | 2,705円/m³ | 2,739円/m³ | 事務のデジタル化・取引の集約（**プラットフォームで動かせる**） |

※伐出費の日墺差は統計の範囲が揃っておらず、人件費と生産性から逆算すると1.4〜1.5倍程度（[日墺比較レポート](austria_japan_stumpage_gap.md) 5.1.1節）

**金額の絶対値は伐出費のほうが大きいが、プラットフォームで手が届くのは販管費のほう。** ideas.md の「販管費は生産性と違って改善が見込める」という着眼は正しい。

## 2. 既存の類似サービス・取組

**丸太については既存の仕組みが厚い。一方、立木では2026年2月に同趣旨のサービスが動き出した。**

| サービス | 実際のモデル | Amazon型か |
|---|---|---|
| **立木取引市場** | **立木のオンラインマッチング**（2026年2月運用開始） | **○ 最も近い。事実上の先行者** |
| デジタル林業戦略拠点 | サプライチェーンの**情報基盤**（県単位、取引機能は将来構想） | × |
| eTREE | **コーディネーター介在型**の調達支援 | × |
| Forstify | **ドイツ**のサービス（2019年時点で試験運用） | 近い（国内ではない） |
| 原木市売市場 | **物理的な仕分けとセリ**。これ自体が共同物流倉庫 | × |
| 中間土場 | 輸送の**中継点**（保管倉庫ではない） | × |
| 「システム販売」 | **相対販売の呼称。ITとは無関係**（後述） | × |

### (a) デジタル林業戦略拠点（林野庁）— 最も重なる

白書の事例2-5「鳥取県デジタル林業コンソーシアム」:

- 木材の生産から流通・加工までの関係者、行政等**29団体**で構成
- 丸太生産 → 木材市場 → 製材・合板工場 → プレカット工場 → 工務店のサプライチェーンで、見積・納品情報や県産材証明を紙運用していたのをデジタル化
- **県産材証明書は約8割のコスト削減**が可能と試算
- 木材の規格や取引数量をシステム内で一括管理
- **将来的には木材需給状況の把握、在庫管理の適正化、取引マッチングの促進を推進**

林野庁は令和7(2025)年度までに北海道・静岡県・鳥取県の3地域へ森ハブからコーディネーターを派遣し、**令和9(2027)年度までに全都道府県でデジタル林業戦略拠点の構築**を目標としている。

→ **「オンラインで供給が見えて注文可能」の部分は、国主導で全国展開が始まっている。**

### (b) eTREE（森未来）— Amazon型ではない

「木材版ZOZOTOWN」と紹介されることがあるが、**実態はWebサイトを持つ木材商社／調達コンサルに近い**。

| 論点 | eTREE | Amazon型 |
|---|---|---|
| 顧客 | **設計士・デザイナー** | 誰でも |
| 価格表示 | **なし** | 全商品に表示 |
| 注文方法 | **問い合わせ・見積依頼**（ヒアリングから対応） | その場で注文・決済 |
| 在庫 | **持たない**（全国の木材事業者と連携して調達） | 自社倉庫に集約 |
| 人手 | **木材コーディネーターが全案件に介在** | セルフサービス |
| 品目 | **製品中心**（フローリング、造作材、カウンター、不燃集成材、焼杉） | — |

**情報の非対称性を人手で埋めるモデル**であり、それを自動化しようという本アイデアとは方向が逆。ただし顧客が**設計士・デザイナー**である点は重要で、これは**買い手が多数・都度・少量**という層。丸太と違ってAmazon型が成立しうる領域を狙っている。それでもセルフサービス化していない理由は要確認。

### (c) Forstify — ドイツの先行事例

当初「原木売買プラットフォーム」として国内の競合に挙げていたが、**ドイツのサービス（forstify.de）**だった。

- 記事は**2019年7月**時点。ドイツ西部ザウアーラントで試験運用中、同年末に全土リリース予定とされていた
- 木材生産者が**原木の種類・価格・強度・太さ・原産地を画像とともに投稿**
- **オンラインマップ上に販売情報が表示**され、加工業者が生産者から直接調達できる
- 運営会社・取扱量・現在の稼働状況は未確認

**構想として無理筋ではないことの傍証**にはなるが、2019年時点の試験運用の記事が最後の情報で、その後の展開は未確認。ドイツは日本と所有構造・路網条件が異なるため、成立条件をそのまま移せるわけではない。

### (d) 原木市売市場 — **これ自体が既に共同物流倉庫**

「競合他社とも物流倉庫を共同化」という構想は、**原木市売市場が既に実現している機能そのもの**。

| 共同物流倉庫の要件 | 原木市売市場 |
|---|---|
| 競合する複数の売り手が持ち込む | ○ 複数の素材生産業者が同じ土場に搬入 |
| 規格別に整理して保管 | ○ 樹種・径級・品質・長さで仕分け、**椪積（ストック）** |
| 複数の買い手が引き取る | ○ 製材工場・合板工場・木材販売業者 |
| 全国展開 | ○ **431事業所**（2023年） |

さらに運搬の分担も確立している（上吉野木材協同組合の例）:

```
山土場 ──[出荷者が搬入]──> 原木市場 ──[買方が引き取り]──> 製材工場
        素材生産業者が負担              製材工場等が負担
```

| 負担者 | 項目 | 金額 |
|---|---|---|
| **出荷者** | 市売手数料 | 売上額の **7.0%** |
| 出荷者 | 椪列料 | **950円/m³** |
| **買方** | **積込料** | **1,000円/m³** |

**「物流倉庫の共同化」に革新の余地はほとんどない。** 物理層は既に整備済みで、しかも料金体系まで確立している。

なお市場間の横断（431事業所がそれぞれ独立している）は空白だが、**丸太は重量物**（運材費150kmで3,800円/m³）のため、**地域を越えて買う経済性が乏しい**。地域内で集約し地域内で消費する現在の形は、丸太に関しては合理的である可能性が高い。

### (d-2) 「システム販売」はITとは無関係 — 用語の整理

**当初この語を根拠に「業界はオンライン化不要な形に移行済み」と論じたが、それは誤読だった。** 「システム販売」と呼ばれるものは2つあり、**どちらもITシステムではない**。

| 呼称 | 実体 | 規模 |
|---|---|---|
| 伊万里木材市場の「システム販売」 | **その市場独自の商品名**。特定顧客への**相対販売** | 同市場で取扱量の98%。**1市場の数字であり業界全体ではない** |
| 国有林材の「安定供給システム販売」 | 林野庁の制度。需要者と**協定を締結し山元から直送** | **国有林の素材販売量の60.5%＝188万m³**（2024年度） |

**したがって、民有林を含む全国の原木市場でセリと相対がどう分かれているかは、確認できていない。** 伊万里の98%を一般化したのは誤りだった。

#### 言えること・言えないこと

**言えること:** 取引が相対・協定へ移行する傾向はある。直送が41.8%で最大、国有林でも協定に基づく直送が素材販売の60.5%。相対はセリより手数料が安い（5%＋650円 vs 8%＋1,000円）。

**言えないこと:** **オンラインマッチングの需要があるかないかについて、直接の証拠は何もない。** 「システム販売」はITではないので、その普及はオンライン化の要否を何ら示さない。

#### 等級判定も障壁ではない

「等級の判定が属人的だから遠隔取引ができない」という説明も成り立たない。原木市売市場には検品・仕分けを行う担当者が常駐し、樹種・径級・品質・長さで実際に仕分けて椪積している。**判定の機能は既に存在する。**

#### 残る仮説

丸太でオンラインマッチングが成立しにくい理由として残るのは、**Amazon型の前提との構造的なずれ**。

| | Amazonが有効な市場 | 林業（丸太） |
|---|---|---|
| 買い手の数 | 多数 | **少数**（製材工場3,547、合板工場154） |
| 購入頻度 | 都度 | **継続**（協定取引） |
| 1回の量 | 少量 | **大量**（合板工場は年10万m³必要） |
| 選択行動 | 比較して選ぶ | **契約で確保する** |

ただしこれは**仮説であって検証されていない**。

### (d-3) 立木取引市場 — 事実上の先行者

**アイデアとほぼ同じものが、2026年2月から立木を対象に稼働している。**

| 項目 | 内容 |
|---|---|
| 名称 | **立木取引市場**（https://kokusanzaikatsuyo.jp/ryuboku/） |
| 運営 | 一般社団法人 国産材を活用し日本の森林を守る運動推進協議会 |
| 運用開始 | **2026年2月** |
| 対象 | **伐採前の立木** |
| 売り手 | 森林所有者、林業事業体 |
| 買い手 | 製材業者、工務店 |
| 仕組み | 売り手が立木情報をオンライン登録 → 買い手が条件に合う木を検索して取引 |
| 狙い | 買い手の選択肢を広げ、**取引の透明性を高める** |
| 実績 | 4月末までに**買い手中心に約30事業者**が登録。出品・成約は「これから積み上げる局面」 |
| 特記 | **三井住友信託銀行と再造林資金の管理に関する覚書**（2026年3月27日）。売買代金の一部を再造林費用として管理 |

「木のフリマサイト」を目指すと報じられている。

#### なぜ丸太ではなく立木なのか

立木取引には、丸太と違って**そもそも市場が存在しなかった**。

| | 原木（丸太） | 立木 |
|---|---|---|
| 市場 | **431事業所** | **存在しなかった** |
| 価格情報 | 統計あり（素材価格） | **市場外取引のため乏しい** |
| 公的な参照値 | — | 国有林の公売結果、日本不動産研究所の調査（逆算値） |

林野庁自身がこう説明している。

> 立木価格は立地条件や林分構成に大きく左右され、**こうした取引が市場外で行われるため、森林所有者や民有林関係者は価格情報が乏しかった**

そのため国有林は立木公売の結果（樹種・径級・本数・材積・品質・位置情報）を公表し、民有林の参照に供している。**情報の非対称が最も大きいのは丸太ではなく立木だった。**

#### ただし立木は遠隔評価がさらに難しい

報道は課題をこう指摘する。

> **写真や説明では品質判断が難しく、樹種や本数、太さ、曲がり、搬出道路の有無で価格が大きく変わる。現地確認で搬出費用が予想より増加する可能性がある**

**価格を決めるのは木そのものより「搬出道路の有無」＝伐出費。** これは本リポジトリの分析（丸太価格と山元立木価格の差の79〜91%が伐出費、[伐出費レポート](log_production_cost.md)）と完全に一致する。

つまり**立木取引の本質は「木の値段」ではなく「その現場でいくらで伐り出せるか」の見積もり**であり、オンラインで解くには伐出費の推定が要る。

#### 立木取引の規模

| | 立木販売 | 素材生産 |
|---|---|---|
| 家族経営体の林業粗収益に占める割合（H30） | **5.5%** | 56.7% |
| 国有林の木材供給量（2024年度） | **176万m³**（丸太換算） | 311万m³ |

**民有林では立木販売は少数派**（家族経営体で粗収益の5.5%）。国有林では立木供給が素材供給の6割弱に相当する規模がある。

### (e) 中間土場 — 「物流倉庫の共同化」とは別物

当初「物流倉庫の共同化は既に進行中」と書いたが、**これは不正確だった**。

出典（北海道立総合研究機構 林産試験場）の定義:

> **中間土場とは、伐採地と原木消費地の中間地点に作られたストックヤードや中継地の総称です。** 中間土場の運送上のメリットの一つは、**原木を集めてロット化した後、トレーラ類で効率的に運べること**です。

| | 中間土場 | ideas.md の「物流倉庫の共同化」 |
|---|---|---|
| 目的 | **輸送の中継**（小型車→トレーラへの積み替え）、運転手の分担 | 競合他社と**在庫を共同保管** |
| 機能 | 通過点 | 保管拠点 |
| 動機 | 2024年問題（超過労働対策） | 物流コスト削減・需給マッチング |
| 共同利用の有無 | **出典に記載なし** | 前提 |

北海道では2016→2019年に急増し2020年で約80箇所（[運材費レポート](log_hauling_cost.md)）。全国調査でも中間土場を経由する運送形態が区分されているが、**最も多いのは山土場からの直送**。

**ただし「原木を集めてロット化する」機能はアイデアと重なる。** これは第3節(a)の「小口業者の価格交渉力」と同じ狙いが、運送の文脈で先に実現しつつあることを意味する。

### (f) 原木市場のシステム販売 — 相対取引への移行は完了しつつある

[流通レポート](log_distribution_flow.md) のとおり:

| 方式 | 手数料 | 整木料 |
|---|---|---|
| 市売（セリ・入札） | 8% | 1,000円/m³ |
| **システム販売（相対）** | **5%** | 650円/m³ |

伊万里木材市場では**システム販売が取扱量の98%**を占める。

## 3. 聞き取り調査の2論点を検証

### (a)「小口の業者は工場に対して価格交渉力がない」→ **裏付けられる**

| 供給側 | 数値 |
|---|---|
| 素材生産を行った林業経営体 | 5,839経営体（2020年） |
| 1経営体当たり平均素材生産量 | **3.5千m³** |
| 年間1万m³以上の経営体が占める生産量 | **全体の約7割** |

| 需要側 | 数値 |
|---|---|
| 大手住宅メーカーの調達方針 | 「品質・性能の確かな木材製品の**大ロットで安定的な調達**」を重視 |
| 合板メーカーの必要量 | 一工場当たり**年間原木消費量が最低10万m³** |

**ロットの非対称性が交渉力の差を生んでいる。** 平均3.5千m³の経営体が、単独で10万m³規模の需要に応えることは不可能。

**→ 共同でロットを作るという発想は正しい。** ただしそれは既に**森林組合の共販所**と**協定取引**が担っている機能でもある。

### (b)「成長しすぎてしまっている苗がある」→ **他にない着眼点**

| 項目 | 数値 |
|---|---|
| 苗木生産量 | 約6,600万本（2024年度）、うち**約6割がコンテナ苗** |
| 苗木生産事業者数 | 878（うちコンテナ苗生産事業者614） |
| 特定苗木（エリートツリー等） | 751万本＝苗木生産量の**約1割**。2030年目標は3割（3,000万本） |

**苗木は在庫として持てない。** 成長してしまうと規格外になり、価値が失われる。一般的な商品と違い、需給ミスマッチが**即座に損失**になる。

これは既存のプラットフォーム（eTREE、原木売買）が扱っていない領域で、**アイデアの独自性が出る可能性がある**。しかも現地の困りごととして実際に挙がっている点が強い。

ただし検討すべき制約:
- 植栽適期（春・秋）に需要が集中する季節商品
- ただしコンテナ苗は適期以外でも高い活着率が見込めるため、この制約は緩和されつつある（既に6割がコンテナ苗）
- 苗木生産は造林計画に基づく受注生産が基本で、見込み生産が少ない可能性

## 4. 「Amazon」モデルの成立条件

Amazonの本質は ①在庫の集約 ②物流の規模の経済 ③検索・比較可能性。品目ごとに成立するか検証する。

| 要素 | 苗木 | 丸太 | 加工後の資材 |
|---|---|---|---|
| **規格化** | △ 樹種・品種・サイズ | **× 個体差が大きい**（径級・長さ・品質・曲がり） | ○ JAS等の規格あり |
| **在庫保管** | **× 成長する・枯れる** | △ 劣化する（山に長期間置くと材質劣化） | ○ 可能 |
| **輸送効率** | ○ 軽量 | **× 重量物**（1m³≒0.8トン）、専用車両（運材車）が必要 | △ |
| **需要の平準性** | × 植栽適期に集中 | ○ 通年 | ○ 通年 |
| **既存の代替手段** | 受注生産 | 原木市場・協定取引・直送 | 商社・建材店・EC |

**丸太が最も難しい。** 規格が個体ごとに違い、重く、専用車両が要り、既に市場という選別機能が存在する。[流通レポート](log_distribution_flow.md) で確認したとおり、**市場の本質的機能は選別（椪積）**であり、これはオンライン化しても誰かが物理的にやらねばならない。

**加工後の資材が最も成立しやすい。** 規格化されており在庫可能。ただし既存ECが存在する。

**苗木は独自性があるが市場規模が小さい。** 生産量6,600万本で、単価を仮に100円としても66億円規模。

## 6. 暫定結論

**価値の柱は2つ。「販管費の削減」と「小口業者の価格交渉力」。**

**(1) 販管費の削減 — 金額インパクトが大きい**

販管費2,705円/m³ は山元立木価格4,026円/m³ の67%に相当する。20%削減で立木価格+13%、50%削減で+34%。白書の鳥取事例が証明書事務で8割削減可能と試算しており、削減余地の存在自体は裏付けられている。

日墺で同水準（2,705円 vs 2,739円）なのは「日本が特別に非効率ではない」ことを示すだけで、**両国とも同程度に非効率である可能性**を否定しない。オーストリアを上限とみなす理由はない。

**(2) 小口業者の価格交渉力 — 課題が実在する**

ロットの非対称性（小口3.5千m³ vs 合板工場10万m³）は統計で裏付けられ、現地聞き取りとも一致する。共同化で直接解ける。

**一方、市場手数料の削減（中抜き）は効果が限定的。** 差額の5%程度（全国平均620円/m³）にすぎない。

**そして伐出費（9,000〜10,400円/m³）はプラットフォームでは動かせない。** ここは路網整備と機械化の領域で、アイデアの射程外。

### 直接の競合は、実は存在しない

当初「競合が強い」と評価したが、個別に確認した結果**モデルが違うものばかりだった**（第2節）。

| アイデアの要素 | 近い動き | 実際の関係 |
|---|---|---|
| オンラインで供給が見えて注文可能 | デジタル林業戦略拠点 | **情報基盤**であり取引機能は将来構想。県単位 |
| 物流倉庫の共同化 | 中間土場 | **輸送の中継点**で保管倉庫ではない。共同利用の実態も不明 |
| 共同でロットを作る | 森林組合の共販所・協定取引 | **これは実質的な競合**。ただし単一組合・単一地域の範囲 |
| 加工後の資材のEC | eTREE | **コーディネーター介在型**でAmazon型ではない |
| 原木のオンライン売買 | Forstify | **ドイツ**のサービス。国内には存在しない |

**「複数の売り手の在庫が横断的に見えて、価格が表示され、その場で注文できる」ものは日本にない。**

### 立木では既に先行者がいる

**同趣旨のサービス「立木取引市場」が2026年2月から稼働している**（第2節 d-3）。しかも情報の非対称が最も大きいのは丸太ではなく**立木**だった（丸太には431の市場があるが、立木には市場がなかった）。

つまりアイデアの核心部分は、**最も筋の良い品目で、既に他者が着手している**。

ただし同サービスも登録は約30事業者、出品・成約は「これから積み上げる局面」で、成否は未確定。**参入余地がないわけではないが、後発になる。**

### 差別化するなら

**(a) 苗木 — 最も有望**

- **共同物流の基盤が存在しない**（丸太の原木市売市場431事業所に相当するものがない）
- **軽量**なので地域を越えた取引に経済性がある（丸太は150km運搬で3,800円/m³）
- **在庫が成長する**という固有の課題があり、需給マッチングの価値が直接的
- 現地聞き取りで実際の困りごととして挙がっている
- **立木取引市場も丸太市場も扱っていない**

ただし市場規模は数十億円規模と小さい。

**(b) 伐出費の見積もり機能**

立木取引市場が直面している課題は「**搬出道路の有無で価格が大きく変わり、現地確認で搬出費用が予想より増加する**」こと。これは本リポジトリの分析（差額の79〜91%が伐出費）と一致する。

**マッチングの場を作ること自体より、「その現場でいくらで伐り出せるか」を遠隔で見積もる機能のほうが本質的な価値**かもしれない。航空レーザ計測や路網データを使えば、地形・搬出距離から伐出費を推定できる可能性がある。白書もドローンレーザ計測による資源調査の普及を記録している。

**(c) 買い手が多数・都度・少量の層**

eTREEが設計士・デザイナーを顧客にしているのは、そこがAmazon型の前提を満たす層だから。ただしeTREE自身はセルフサービス化していない。**なぜコーディネーターを外せないのかは要確認。**

### 丸太については

物理層（原木市売市場431事業所）が既に共同物流倉庫として整備済みで、料金体系まで確立している。**この層に新規参入する意義は薄い。**

情報層については、**オンラインマッチングの需要があるかないかを判断できるだけの証拠がない**というのが正直なところ。Amazon型の前提とのずれ（買い手が少数・継続・大量）は指摘できるが、仮説の域を出ない。
