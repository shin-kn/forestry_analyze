# アイデア検証: 耕作放棄地への植樹

作成日: 2026-09-07
対象: [ideas.md](../user_docs/ideas.md) 「本命 > 耕作放棄地に植樹」

出典:
- 令和7年度 森林・林業白書（`ref/official/white_paper/japan/md/`）
- 荒廃農地面積・早生樹の性能は「参考リンク」を参照

---

## 0. 検証する仮説

ideas.md の記述:

- **現状**: 地形の影響もあり、重機が入って木をがつがつ切れるところは少なく、交通の便がいいところも難しい
- **アイディア**: 現在耕作放棄地になっているような畑や田んぼに成長の早い木を植える。交通の便もいいので、採算性があがるのでは？（運搬費などが抑えられるので立木価格も平均よりはるかに高そう）
- **課題**: 耕作地を転換するのは法律が厳しい／採算の問題（土地取得コスト）

仮説の中心は2つ。**(1) 交通の便＝運搬費の削減による採算改善**、**(2) 成長の早い樹種**。以下、規模・制度・樹種・採算の順に検証する。

---

## 1. 対象となる土地の規模

**荒廃農地は 25.7万ha**（2024年3月末時点）。内訳が重要。

| 区分 | 面積 |
|---|---|
| 再生利用が**可能** | 9.4万ha |
| 再生利用が**困難** | **16.3万ha** |
| 合計 | 25.7万ha |

さらに2023年度は、新規発生 2.5万ha に対し再生利用 1.0万ha で、**年1.5万haずつ純増**している。発生原因は農業者の高齢化・病気・死亡、担い手・労働力不足。

比較のため: 日本の人工造林面積は**年3.5万ha**。再生利用困難な荒廃農地16.3万haは、その**約4.7年分**の面積にあたる。規模としては十分に事業対象になる。

---

## 2. 課題「法律が厳しい」は既に手当てされている

白書にこう書かれている。

> 「農山漁村の活性化のための定住等及び地域間交流の促進に関する法律」に基づく農用地の保全等に関する事業において、放牧等の粗放的利用や鳥獣緩衝帯の整備、**林地化**に取り組むことができることとされている。**林地化に当たっては農地転用手続の迅速化が措置されている**ことから、山際など条件が悪く維持管理が困難な荒廃農地を林地化して管理・活用する取組が進められている。

施策編にも独立した項目がある。

> **イ 再生利用が困難な荒廃農地の森林としての活用**
> 農地として再生利用が困難であり、森林として管理・活用を図ることが適当な荒廃農地について、**地域森林計画へ編入**し、編入後の森林の整備及び保全を推進した。

さらに林野庁は令和5(2023)年に「**荒廃農地における植林 優良な取組事例集**」を公表している（市町村担当者が検討・調整を進めるための参考資料）。

**つまり規制緩和・制度整備・事例集の公表まで既に済んでいる。** ハードルは制度ではなく、地域の合意形成と地域森林計画への編入という実務に移っている。

**ただし対象は限定される。** 迅速化措置の対象は「農地として**再生利用が困難**」なもの。まだ農地として使える土地、特に農業振興地域の農用地区域内にある優良農地の転用は依然として厳しい。アイデアの言う「畑や田んぼ」のうち、**現役で使える農地は対象外**と考えるべき。

---

## 3. 「成長の早い木」の選択肢

### (a) 早生樹

林野庁が調査対象としているのは**センダン、コウヨウザン、チャンチンモドキ、ヤナギ類**。

- **20〜30年で収穫**できる（スギ・ヒノキは50年前後）
- 広島県庄原市の52年生コウヨウザン林分: 個体密度1,164本/ha、平均樹高20.2m、平均胸高直径26.5cm、林分材積**1,006m³/ha** — 当該地域の**スギ一等地の倍以上**の成長
- **広島県では既に荒廃農地でのコウヨウザン植林が実施されている**（広島県森林整備・農業振興財団＋広島県樹苗農業協同組合）

白書は早生樹について、燃料用途を念頭に「経済産業省と連携し、燃料用途としても期待される早生樹の植栽等に向けた実証事業を支援している」と書いており、国有林でも「早生樹の導入」に取り組んでいる。

### (b) 改良スギ — エリートツリー／特定苗木

こちらは既存のスギ流通にそのまま乗る点が強み。

| 項目 | 内容 |
|---|---|
| 特定母樹の指定数 | **581種類**（うちエリートツリー **398種類**）2026年3月末 |
| 指定基準 | 成長量が同様の環境下の対照個体と比較して**おおむね1.5倍以上**、材の剛性や幹の通直性に著しい欠点がなく、雄花着生性が一般的なスギ・ヒノキのおおむね半分以下 |
| 期待される効果 | **下刈り期間の短縮**による育林費用の削減、**伐期の短縮**による育林費用回収期間の短縮、CO₂吸収量の向上 |
| 生産実績（2024年度） | 751万本（スギ649万、グイマツ88万、ヒノキ13万）= 苗木生産量の**約1割** |
| 政府目標 | 2030年に苗木生産量の**3割**（3,000万本程度）、2050年に**9割** |

雄花着生性が半分以下という基準は花粉症対策も兼ねており、政策的な後押しが強い。

### 比較

| | 早生樹 | 改良スギ（特定苗木） |
|---|---|---|
| 成長 | スギの倍以上（コウヨウザンの例） | 対照個体の約1.5倍 |
| 伐期 | 20〜30年 | スギの標準より短縮 |
| 出口（用途・買い手） | **未確立**。燃料材が主に想定されている | 既存のスギ流通・加工体制にそのまま乗る |
| 苗木の供給 | 限定的 | 年751万本、2030年に3,000万本目標 |

**出口の有無が決定的な差。** 早生樹は成長は速いが、材が何に売れるかが定まっていない。燃料材が主用途なら単価は繊維材並み（製材用の1/4程度）で、[立木価格の比較レポート](austria_japan_stumpage_gap.md) で見たとおり既存工法でも採算限界の水準になる。

---

## 4. 採算の検証

土地取得コストを論じる前に、**そもそも造林の採算が成立するか**を確認する必要がある。

白書の1ha試算（スギ人工林50年生・主伐）:

- 造林初期費用（地拵え〜植栽〜下刈り）: **307万円/ha**
- 山元立木価格（森林所有者の収入）: **181万円/ha**

→ **土地代ゼロでも126万円/haの赤字。** これは既存林地での数字であり、耕作放棄地ではここに土地取得コストが上乗せされる。

改良スギの伐期短縮・下刈り削減が効いても、この差を埋めるには造林初期費用の削減と伐期短縮による割引現在価値の改善の両方が必要になる。

### 仮説(1)の検証 — 交通の便による採算改善

**「運搬費などが抑えられるので立木価格も平均よりはるかに高そう」という読みは、数字の上で裏付けられる。**

日本林業の最大のボトルネックは路網密度で、**25.6 m/ha**（オーストリアは45 m/ha）。耕作放棄地は平坦地・農道沿いのため、この制約を丸ごと回避できる。

- 農道が使えるため集材距離が極端に短い
- 平坦地のため重機が入る＝機械化前提の作業システムが組める
- 架線集材が不要

効き方を金額で見る。[立木価格の比較レポート](austria_japan_stumpage_gap.md) の分解を使う。

| | 全国平均（スギ, 2025） | 耕作放棄地で期待される値 |
|---|---|---|
| 丸太価格（製材工場着） | 15,400円/m³ | 同じ（市場価格） |
| 伐出費のうち集材 | 3,810円/m³（民間試算） | 大幅減 |
| 運材費・流通 | — | 減（幹線道路に近い） |
| **山元立木価格** | **4,026円/m³** | **上振れ** |

丸太価格と山元立木価格の差は**11,374円/m³**あり、その中身が伐出費・運材費・流通マージン。集材3,810円の大半と運材費が削れるなら、**山元立木価格は8,000〜10,000円/m³の水準もありうる**。これはオーストリアの立木価格（10,928円/m³）に迫る値で、平均の2倍以上にあたる。

**仮説の方向は正しく、インパクトも大きい。** ただし前提として、丸太価格が全国平均並みに取れること（＝出口が確保できていること）が必要。ここが樹種選択と直結する。

### 不利な点

- **土壌条件**: 農地土壌は林地と条件が違う（排水、pH、施肥履歴）。雑草の繁茂が激しく、下刈り負担が増える可能性
- **分散**: まとまった面積を確保しにくい。山際の条件の悪い農地から荒廃するため、1筆あたりが小さい
- **獣害**: 人里・農地に近いためリスクが高い（ideas.md「獣害抑制による価値創出」と表裏）

## 5. 論点の再整理

| 論点 | 評価 |
|---|---|
| 耕作地の転換は法律が厳しい（既出） | **再生利用困難な荒廃農地は既に迅速化措置あり**。制度・事例集とも整備済み。優良農地は依然厳しい |
| 土地取得コスト（既出） | 造林は土地代ゼロでも126万円/ha赤字。**取得より借地・施業受託**のほうが現実的か |
| 交通の便による採算改善（既出） | **裏付けあり**。集材3,810円/m³＋運材費が削れれば山元立木価格は8,000〜10,000円/m³もありうる（平均4,026円の2倍以上） |
| **早生樹 vs 改良スギ** | 早生樹は成長で勝るが出口未確立。改良スギは既存流通に乗る |
| **出口（用途・買い手）** | 早生樹の主用途は燃料材。単価は製材用の約1/4。**運搬費が浮いても出口が安ければ相殺される** |
| **土壌・雑草** | 農地土壌での活着と下刈り負担は要検証 |
| **獣害** | 人里に近く高リスク |
| **面積のまとまり** | 分散した小面積をどう束ねるか |

## 6. 暫定結論

**[アイデア1（ドローン）](drone_log_transport.md) より筋が良い。** 理由は4つ。

1. **制度が既に整備されている** — 規制緩和済み、地域森林計画への編入ルートあり、事例集も公表済み
2. **対象地が明確で規模もある** — 再生利用困難16.3万ha、年1.5万haずつ増加
3. **先行事例がある** — 広島県のコウヨウザン植林
4. **仮説(1)の効き方が大きい** — 交通の便による運搬費削減で、山元立木価格が平均の2倍以上になりうる

**2つの仮説のうち、効くのは(1)「交通の便」のほう。** 立木価格は「丸太価格 − 伐出費 − 運材費 − 流通マージン」で決まり、耕作放棄地はこの控除項を丸ごと圧縮する。一方(2)「成長の早い樹種」は伐期を縮めて回収期間を早めるが、**単価そのものは上げない**。むしろ早生樹を選ぶと出口が燃料材（製材用の約1/4）になり、せっかく浮いた運搬費を相殺しかねない。

したがって**樹種は改良スギ（特定苗木）を軸に置くのが整合的**。既存のスギ流通に乗るため丸太価格を全国平均並みに取れ、成長1.5倍・下刈り短縮の効果も得られる。早生樹は出口が確立してから検討する順序になる。

なお、造林の採算は土地代ゼロでも126万円/ha赤字という前提を踏まえると、**土地を取得する構想は分が悪い**。借地または施業受託の形で、土地取得コストを負わずに立地の優位だけを取る設計のほうが成立しやすい。
