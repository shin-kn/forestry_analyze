# 地球温暖化に備えた樹種・品種の試験 — 今そこに生えていないものを植える動き

作成日: 2026-09-09

出典:
- 令和7年度 森林・林業白書（`ref/official/white_paper/japan/md/`）
- 分布・試験の情報は「参考リンク」を参照

用語は [スギの用途別レポート](sugi_price_by_use.md) 第0節の定義に従う。

---

## 0. なぜこの問いが立つか

温暖化でスギの適地が縮小するという予測がある。では代わりに何を植えるのか。**「今そこに生えていない樹種・品種」を試している動き**を整理する。

---

## 1. 前提 — スギの分布と、温暖化で何が起きるか

### スギの天然分布

| | 位置 |
|---|---|
| **北限** | 青森県鰺ヶ沢町の**矢倉山** |
| **南限** | 鹿児島県**屋久島** |

気候帯は**冷温帯（山地帯、ブナ帯）**。

**標高範囲**

| 地域 | 標高 |
|---|---|
| 本州 | **0〜2,050m** |
| 四国 | **300〜1,400m** |
| 九州 | **300〜1,850m**（屋久島） |

**南に行くほど下限標高が上がる。** 本州では海抜0mから生えるのに、四国・九州では300m以上。**南方の低地は既に暑すぎる。**

なお植栽であれば分布はもっと広く、北は**利尻島**、南は**沖縄本島北部**、海外では台湾・朝鮮半島・中国・ヒマラヤ地方まで造林例がある。

### 温暖化の予測

- **関東以西の太平洋側・低標高のスギ林は2090年代までに衰退**が見込まれる
- 降水量が約30%減少すれば、関東平野北西側や東北太平洋側のスギ林も衰退が予想される
- 温暖化後も適地が維持される地域（**refugia**）を特定する研究も進んでいる

**課題は「スギをどこまで南に植えられるか」ではない。** 今スギが植わっている低標高地が適地でなくなり、**下限標高が全国的に上がっていく**ことが問題。

---

## 2. 備えは2方向で進んでいる

| | **(A) 樹種を替える** | **(B) 品種を替える** |
|---|---|---|
| 中身 | スギより暖かい帯の樹種を導入 | スギのまま、耐性のある系統を選抜 |
| 対象 | **コウヨウザン、センダン** | **エリートツリー、気候変動適応品種** |
| 実施主体 | 森林総研＋県、国有林、民間企業 | 林木育種センター |

---

## 3. (A) 樹種を替える

### 対象樹種の位置づけ

| | **スギ** | **コウヨウザン** | **センダン** |
|---|---|---|---|
| 学名 | *Cryptomeria japonica* | *Cunninghamia lanceolata* | *Melia azedarach* |
| 原産・自生 | **日本固有種** | **中国南部・台湾**（外来） | 在来だが分布は国際的 |
| 気候帯 | **冷温帯**（ブナ帯） | **暖温帯**（照葉樹林帯） | **熱帯・亜熱帯アジア〜豪州** |
| 日本での南限 | **屋久島** | （植栽のみ） | **沖縄**、小笠原にも |
| 日本での北限 | 青森県鰺ヶ沢町 | 植栽で宮城・新潟以西 | **伊豆半島以西** |

```
熱帯・亜熱帯          センダン
     ↑
暖温帯・照葉樹林帯     コウヨウザン
     ↑
冷温帯・ブナ帯         スギ
```

**スギの適地が上（北・高標高）へ逃げる分を、下から順に埋める候補**という構図になっている。

補足:
- **コウヨウザン**は江戸時代に渡来し、宮城県・新潟県以西〜九州の**照葉樹林帯の寺社等に広く植栽**されてきた実績がある。中国では重要な造林樹種
- **センダン**は自生分布が朝鮮半島南部、中国、インド、ネパール、スリランカ、インドネシア、ニューギニア、オーストラリアに及ぶ。学術的な原産域は「熱帯・亜熱帯アジアから北・東オーストラリア」で、**実質的に熱帯性樹種**

### 試験の一覧

| 実施主体 | 内容 | 樹種 |
|---|---|---|
| **森林総研 林木育種センター＋岐阜県** | 温帯高標高域（ボーダー域）での**生育適地把握**。令和4〜9年度 | コウヨウザン |
| **群馬県林業試験場＋利根沼田森林管理署** | 植栽試験（2020年報告） | コウヨウザン |
| **近畿中国森林管理局** | スギ・ヒノキ以外に選択肢を広げるための植栽試験 | センダン・コウヨウザン |
| **福井県総合グリーンセンター** | 生産の手引きを策定（令和5年3月） | センダン・コウヨウザン |
| **群馬県立農林大学校** | 苗木育成調査 | センダン |
| **住友林業 日向森林事業所** | 熊本県・宮崎県の社有林で試験植栽 | コウヨウザン等 |
| **広島県森林整備・農業振興財団＋広島県樹苗農業協同組合** | **荒廃農地への植林** | コウヨウザン |

このほか林野庁「早生樹利用による森林整備手法検討調査委託事業」（平成30年度報告書）、森林総研「コウヨウザンの特性と増殖マニュアル」が公表されている。**都道府県・大学・国有林にも植栽があり**、特性解明・優良木の選抜・苗木生産技術・育林技術が並行して進む。

### 試験地の選び方に意図がある

岐阜（高標高のボーダー域）、群馬、福井といった**本来の適地より寒い場所**が並ぶ。**分布北限・高標高限界を実測で確かめる設計**になっている。

### 明確な制約 — 冬期被害

福井県の手引きは率直に書いている。

> センダン、コウヨウザンはいずれも**暖地に生育する樹種**であり、雪国の福井県では**冬期被害を受けるリスクが高くなります**

**「南の木を北へ」は無条件ではない。** 寒害・雪害が上限を規定する。

### 成長性能の裏付け

広島県庄原市の52年生コウヨウザン林分:

| 項目 | 数値 |
|---|---|
| 個体密度 | 1,164本/ha |
| 平均樹高 | 20.2m |
| 平均胸高直径 | 26.5cm |
| 林分材積 | **1,006m³/ha** |

**当該地域のスギ一等地の倍以上**の成長。センダン・コウヨウザンはいずれも**20〜30年で収穫**でき、スギ・ヒノキ（50年前後）より伐期が短い。

---

## 4. (B) 品種を替える — 気候変動適応品種

林木育種センターは日本最大の林木育種機関で、**約2,400の改良品種**を開発している。その中に **乾燥耐性に優れた気候変動適応品種** が含まれる。

白書の位置づけ（`chap1_1_3`）:

> 令和4(2022)年に策定された「森林・林業・木材産業分野の研究・技術開発戦略」に基づき、（中略）**花粉発生源対策や気候変動適応等に対応した優良品種の開発**、**気候変動が国内外の森林・林業に及ぼす影響の予測**（中略）等の研究・技術開発を推進する

**特定母樹（エリートツリー等）の状況**

| 項目 | 数値 |
|---|---|
| 特定母樹の指定数 | **581種類**（うちエリートツリー **398種類**）2026年3月末 |
| 指定基準 | 成長量が対照個体の**おおむね1.5倍以上**、雄花着生性が一般的なスギ・ヒノキのおおむね半分以下 |
| 特定苗木の生産 | 751万本＝苗木生産量の**約1割** |
| 政府目標 | 2030年に**3割**（3,000万本程度）、2050年に9割 |

**(B) は「スギを諦めない」路線。** 樹種転換と違い、既存のスギ流通・加工体制にそのまま乗る点で有利（[耕作放棄地への植樹レポート](farmland_afforestation.md) 参照）。

## 5. 熱帯樹種の国内試験は見当たらない

インドネシア等で植林される**熱帯マツ**は、熱帯地域の植林樹種の**34%**を占める主力。

| 樹種 | 分布 |
|---|---|
| メルクシマツ（*Pinus merkusii*） | インドネシア・東南アジア |
| カリビアマツ（*Pinus caribaea*） | 同上 |
| ケシアマツ（*Pinus kesiya*） | 同上 |

しかし**日本国内での林業用試験は確認できなかった。**

日本で唯一の亜熱帯である沖縄でも、造林樹種は在来種が中心:

- 針葉樹: **リュウキュウマツ**（県木）、**イヌマキ**
- 広葉樹: イジュ 等
- **センダン**（家具材）

沖縄県森林資源研究センターは97樹種の材質を整理しているが、**熱帯樹種の導入試験ではなく在来有用樹の活用**が軸になっている。

### 考えられる理由

1. 暖温帯樹種（コウヨウザン・センダン）ですら**本州で冬期被害が問題になる**段階
2. 熱帯樹種はさらに耐寒性が低く、沖縄以外では越冬できない
3. 沖縄は森林面積が小さく、林業の規模も限られる

**ただしセンダンは自生分布が熱帯・亜熱帯アジア〜豪州に及ぶため、実質的には熱帯性樹種の試験が既に行われているとも言える。**

## 6. 共通して残る課題 — 用途（出口）

白書は早生樹について、経産省と連携した実証を**燃料用途**の文脈で記述している（`chap3_2_3`）。

> 経済産業省と連携し、**燃料用途としても期待される早生樹**の植栽等に向けた実証事業を支援している

[スギの用途別レポート](sugi_price_by_use.md) のとおり、**燃料材は単価が最低の用途**。成長が速くても出口が燃料材なら採算は厳しい。

| | 早生樹 | 改良スギ（特定苗木） |
|---|---|---|
| 成長 | スギ一等地の倍以上（コウヨウザンの例） | 対照個体の約1.5倍 |
| 伐期 | 20〜30年 | スギ標準より短縮 |
| **出口** | **未確立**（燃料材が主に想定） | **既存のスギ流通にそのまま乗る** |

---

## 7. まとめ

- 温暖化への備えは **(A) 樹種転換** と **(B) 品種改良** の2方向で並行して進んでいる
- **(A) の対象はコウヨウザンとセンダン**で、いずれも**スギより南（暖かい帯）**の樹種。国・県・国有林・民間企業が試験を実施中
- 試験地は**本来の適地より寒い場所**に置かれ、北限・高標高限界を測る設計。制約は**冬期の寒害・雪害**
- **(B) では林木育種センターが乾燥耐性の気候変動適応品種を開発済み。** 特定母樹581種類、2030年に苗木の3割が目標
- **熱帯樹種（メルクシパイン等）の国内林業試験は見当たらない。** ただしセンダンは実質的に熱帯性樹種
- 共通の課題は**用途（出口）**。早生樹の主用途が燃料材だと採算が厳しい
