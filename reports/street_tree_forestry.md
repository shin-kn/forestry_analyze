# アイデア検証: 街路樹を林業で活用する

作成日: 2026-09-08

出典:

- 街路樹の本数・樹種・管理費、サクラ材の特性は「参考リンク」を参照

---

## 0. 検証する仮説

ideas.md の記述:

- **現状**: 街路樹が倒れたり腐ったりすることが多く（要検証）、また植え替えなどの手間もかかる
- **アイディア**: 街路樹の管理を林業会社が行う。木の種類は高級とされる桜などにする。定期的に切って、また植える。

検証すべき論点は4つ。**(1) 現状認識は正しいか、(2) 市場規模、(3)「桜＝高級材」は成立するか、(4) 林業会社が担う合理性。**

---

## 1. 現状認識の検証 — 「倒れたり腐ったりする」は正しい

### 街路樹の構成（2022年、高速道路会社管理分を除く）

| 樹種 | 本数 | 割合 |
|---|---|---|
| イチョウ | 52万本 | 8% |
| **サクラ類** | **52万本** | **8%** |
| ケヤキ | 45万本 | 7% |
| ハナミズキ | 35万本 | 6% |
| トウカエデ | 30万本 | 5% |

総樹種数は**高木545種、中低木607種**。サクラ類が8%であることから、高木の総数は**約650万本**と逆算できる（※本レポートの計算。原典は割合のみ）。

### ソメイヨシノの状態 — 「要検証」への回答

| 項目 | 内容 |
|---|---|
| 寿命 | **60〜70年** |
| 腐朽 | **枝や幹の腐朽が進行しやすい**。枝葉が繁茂し元気に見えても、幹に洞があったり、きのこが生えていることがある |
| その他の問題 | 歩道の**根上がり**、病気（伝染病のまん延）に弱い |
| 植栽時期 | 戦後、特に**1964年東京五輪前後**に全国へ広がった |
| 現在の動き | 全国的に他品種のサクラへの**植え替えが進行中** |

**1964年前後に植えたものが寿命60〜70年を迎えているため、今まさに更新期にある。** 現状認識は正しく、しかも時期的に追い風。

### 行政側の動き

[生きた木の構造物レポート](living_wood_structures.md) で確認したとおり、倒木・落枝事故が相次いだことを受け、国土交通省は**点検手法の初の指針**を策定し全自治体へ通知する動きにある。点検優先度をA〜Cの3段階に区分し、最高リスク「A」は年1回の定期巡回、個体ごとの**街路樹カルテ**による管理が求められる。

**点検・診断の需要が制度的に発生している。**

---

## 2. 市場規模 — 管理費

### 剪定費（1本あたり）

| 樹高 | 費用 |
|---|---|
| 0〜3m（低木） | 2,500〜5,000円 |
| 3〜4m（中木） | 7,000〜12,000円 |
| 4〜5m（中高木） | 13,000〜18,000円 |
| **5〜7m（高木）** | **20,000〜25,000円** |

年間の維持管理費は**約1.5万円/本**（東京の例）。

高木約650万本 × 1.5万円 ≒ **年間1,000億円規模**（※粗い試算）。

### コストを押し上げる要因

- **高所作業車**が必要
- 中央分離帯では**車線規制**を伴う
- **根上がりによる舗装補修費**が別途かかる
- 樹木は成長するため管理費は逓増する。研究例では**20年で管理費が7倍以上**に膨らんだケースがある

**市場は大きく、しかも自治体は費用の増大に苦しんでいる。** 伊勢新聞が県予算の検証記事で「かさむ剪定費」を取り上げるなど、財政課題として認識されている。

## 3. 「桜＝高級材」は成立するか — 最大の落とし穴

**街路樹のサクラと、材として価値のあるサクラは別物。**

| | ソメイヨシノ | ヤマザクラ |
|---|---|---|
| 位置づけ | 園芸品種（クローン） | 野生種 |
| 街路樹での採用 | **主流** | 少ない |
| 寿命 | 60〜70年 | **200〜300年** |
| 腐朽・病気 | 進行しやすい／弱い | **保存性が非常に高く病気に強い** |
| 材としての価値 | 低い | **高級家具材・造作材・楽器材・彫刻材** |

ヤマザクラは日本のサクラの中で最も木材として有用とされ、材質は素直で反り・狂いが少なく、粘りがあって強度も高い。耐水性が高くキクイムシ等の虫害にも強い。切削加工が容易で表面がきれいに仕上がるため、**江戸時代の浮世絵や書籍の版木はほとんどヤマザクラ**だった。

しかし、アイデアを成立させる上で問題が3つある。

### (a) 街路樹の主流はソメイヨシノで、材価値がない

しかも腐朽が進んでいる個体はなおさら値がつかない。

### (b) 街路樹は用材の形状にならない

街路樹は**日陰と景観のために枝張りを作る**。[スギの用途別レポート](sugi_price_by_use.md) で確認したとおり、材の価値は**通直性**で決まる。製材は丸太から角材・板材を切り出す加工なので、曲がりや節があると歩留まりが大きく落ちる。

剪定を繰り返した街路樹は、幹が短く、枝の跡（節・入り皮）だらけになる。**製材の歩留まりは極端に低い。**

### (c) 樹形の要求が正反対

ヤマザクラに植え替えたとしても:

- 用材になるまで**数十年**かかる
- 用材として採るには**通直に育てる**必要があるが、それは街路樹に求められる樹形（枝張り、緑陰）と両立しない

**「街路樹として植えて、用材として収穫する」は、樹形の要求が正反対なので成立しない。**

---

## 4. 作業の性質が林業と違う

| | 林地 | 街路樹 |
|---|---|---|
| 作業単位 | 面的（ha単位） | **単木** |
| 主要機械 | ハーベスタ、フォワーダ | **高所作業車** |
| 交通 | 林道 | **車線規制が必要** |
| 合意形成 | 森林所有者 | **沿道住民**（国交省が合意形成事例集を公開するほど難航） |
| 搬出 | 集材が最大コスト（3,810円/m³） | 舗装路上のため搬出自体は有利 |

搬出条件だけを見れば街路樹は有利だが、**単木作業・高所作業車・交通規制のコストがそれを上回る**。

そして必要な技能は、チェーンソー＋ロープワーク＋高所作業を組み合わせた**特殊伐採（アーボリカルチャー）**であり、林業の作業システムとは別物。林業会社が持つ伐倒技術と樹木の知識は素地になるが、そのままでは使えない。

## 5. 論点の再整理

| 論点 | 評価 |
|---|---|
| 街路樹が倒れる・腐る（既出、**要検証**） | **正しい**。ソメイヨシノは寿命60〜70年で腐朽しやすく、五輪前後の植栽が今まさに更新期 |
| 植え替えの手間（既出） | **正しい**。全国的に植え替えが進行中。合意形成が難航し国交省が事例集を公開 |
| 市場規模 | **大きい**。高木約650万本、年1.5万円/本で約1,000億円規模。管理費は逓増（20年で7倍の例） |
| **「桜＝高級材」** | **成立しない**。街路樹の主流はソメイヨシノで材価値なし。ヤマザクラは有用だが街路樹には少ない |
| **樹形の両立** | **不可能**。街路樹は枝張り、用材は通直性。要求が正反対 |
| **作業の性質** | 林業ではなく**特殊伐採（アーボリカルチャー）**。単木・高所作業車・車線規制 |
| 追い風 | 国交省の点検指針策定、倒木事故の頻発、自治体の管理費増大、更新期の到来 |

---

## 6. 暫定結論

**「街路樹の管理を林業会社が行う」は筋が良い。ただし「高級材を収穫する」部分は切り離すべき。**

### (a) 管理受託 — 成立する

- 市場が大きく（約1,000億円規模）、自治体は管理費の増大に苦しんでいる
- 倒木事故を受けて**点検・診断の需要が制度的に発生**している（国交省の指針策定）
- 1964年前後の植栽が更新期を迎え、**植え替え需要が全国で立ち上がっている**
- 林業会社は伐倒技術と樹木の知識を持ち、参入の素地がある

ただし必要な技能は特殊伐採であり、**人材育成の投資が要る**。

### (b) 用材としての収穫 — 成立しない

- 街路樹の主流ソメイヨシノは材価値がない
- 街路樹の樹形（枝張り）と用材の要求（通直性）が正反対
- ヤマザクラに植え替えても用材化に数十年かかり、かつ樹形を両立できない

### (c) 副次的な出口はある

- 伐採木を**燃料材・チップ**として出す。規格条件が緩く、曲がり材・細切れでも受け入れられる（[スギの用途別レポート](sugi_price_by_use.md) 参照）
- 太い個体を**銘木・一枚板**として個別に売る。街路樹のケヤキ・イチョウは大径になる。ただしロットにならず、単発の商いになる

### 再定義するなら

> **街路樹の点検・診断・剪定・更新を林業会社が一括受託し、発生材を可能な範囲で燃料材・銘木として出口につなぐ。**

**収益の主軸は「材」ではなく「役務」。** これは他のアイデアと構造が違う点で、林業の採算が土地代ゼロでも赤字（造林費307万円/ha vs 山元立木価格181万円/ha）という前提を踏まえると、**材に依存しない収益源を持てることはむしろ強み**になる。
