# 課題整理

## README

- 網羅しない、目についてあとfeatureされたものだけを行う

## 川上

- コストと価格の採算が合っていない
    - 価格が安すぎる
        - 価格はグローバルで決まるので変えられない
    - コストが高い（コストが決定的）
        - 初期造林費用(地拵え〜植栽〜下刈り)のほうが立木価格より高い
        - [参照レポート](../reports/austria_japan_stumpage_gap.md)
- 採算が取れないので、従事者状況が悪化
    - 人口減少・若年者層の低下
    - 事故が多い

## 川中

- JAS格付けが低い
    - 認証工場も増えていない(機械等級は微増だが目視等級は減少)
- 乾燥材が作れない(中小が)
    - 敷地・人員・投資の制約で乾燥設備を持てない
- 大径材に設備が対応していない
    - 間伐材前提の「中丸太から柱角」の設備のまま。川上の大径化とズレている
- 直送が少ない(コストに関連するのでは)
    - 直送率は横ばいで、むしろ微減

## 川下

- 建築用材(全需要の約32%、うち住宅が大部分)の需要が落ち込んでいる
- 建物の木材化が進んでいる
    - 中大規模の建物も法律改正などで木材化できるように
        - 規格化が進んでいない
